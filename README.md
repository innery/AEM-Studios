
# Project Battle Royale 🎮

## 🧾 Genel Bilgi

**AEM Studios** tarafından geliştirilen bu proje, İstanbul Sabahattin Zaim Üniversitesi "Oyun Programlama" dersi kapsamında final projesi olarak hazırlanmıştır.

Unity oyun motoru ile geliştirilen bu proje, **Battle Royale** temalı bir 3D oyun olup 3 kişilik bir ekip tarafından hayata geçirilmiştir. Oyun, yaklaşık **2000x2000 metre** büyüklüğündeki bir adada geçmektedir.

## 🧩 Kullanılan Teknolojiler ve Araçlar

- 🎮 Unity Game Engine (2022.x veya üzeri)
- 💻 C# ile yazılmış oyun içi scriptler
- 🧱 Unity Asset Store'dan temin edilen ücretsiz 3D modeller ve çevresel asset’ler
- 🎥 [YouTube Tanıtım Videosu](https://youtu.be/nO4ktCF3uMQ)

## 🚀 Özellikler

- Geniş 3D oyun haritası (2000x2000 m)
- Temel Battle Royale oyun mekaniği
- Oyuncu hareketi, düşman etkileşimi ve oyun alanı daralması gibi temel mekanikler
- Asset Store'dan alınan ücretsiz materyallerle zenginleştirilmiş çevre ve atmosfer
- C# ile yazılmış özelleştirilmiş oyun scriptleri

## 🔧 Projeyi Çalıştırmak İçin

1. Bu repoyu klonlayın:
   ```bash
   git clone https://github.com/innery/Project_Battle_Royale.git
   ```

2. Unity Hub üzerinden açın:
   - Unity Hub → `Add` → Proje klasörünü seçin
   - Gerekli Unity sürümünü yüklediğinizden emin olun (örn. 2022.3.x)

3. Sahneyi (`.scene` dosyasını) açarak çalıştırabilirsiniz.
