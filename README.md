# AEM Studios

Unity tabanlı yapılan oyun projesi. 
Battle Royale temalı olan bu oyun, Oyun Programlama Final Projesi için yapılmıştır. 3 kişilik bir ekiple yaptığımız bu oyun, 3D Gameplay içeren 2000X2000 metre alanı olan bir ada üzerinde geçmektedir.
Unity Asset Store'dan kullandığımız free-assetlerle beraber hazırladığımız bu projede, C# temelli kodlar yazarak bizim için uygun scriptleri oluşturduk.
